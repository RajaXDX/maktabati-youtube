# مكتبتي — واجهة روابط يوتيوب

موقع عربي ثابت يعمل على GitHub Pages. تضيف روابط فيديو يدويًا، وتبحث في مكتبتك وتشغّلها داخل مشغّل YouTube الرسمي. صفحة القنوات تحاول عرض قائمة رفع القناة داخل مشغّل YouTube عندما يتوفر اسم مستخدم متوافق، وتوفر رابطًا لفتح القناة على YouTube. مكتبة الروابط محفوظة في `localStorage` للمتصفح الحالي.

## تشغيله محليًا

افتح `index.html` في متصفح حديث.

## نشره على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع `index.html` و`channels.html` و`README.md` إلى جذر المستودع.
3. افتح إعدادات المستودع ثم **Pages**.
4. اختر النشر من الفرع الرئيسي (`main`) ومجلد الجذر (`/root`)، ثم احفظ.
5. استخدم الرابط الذي يظهر في صفحة Pages بعد اكتمال النشر.

## ملاحظات

- الموقع لا ينسخ ملفات الفيديو ولا يزيل الإعلانات. التشغيل يتم عبر مشغّل YouTube، وقد تظهر إعلانات بحسب إعدادات YouTube.
- أضف فقط الفيديوهات التي يسمح أصحابها بتضمينها؛ بعض المقاطع قد تمنع التشغيل المضمّن.
- هذه المكتبة شخصية ومحلية في المتصفح. لم تُضف خدمة بحث شاملة في YouTube أو مفتاح API.
- صفحة القنوات تستخدم مشغّل YouTube الرسمي لعرض قائمة الرفع عند دعم اسم المستخدم. واجهة المستخدم لا تستخرج بيانات الفيديوهات إلى بطاقات مستقلة؛ ذلك يحتاج ربطًا بواجهة YouTube Data API.
- أسماء المستخدمين الحديثة قد لا تعمل مع قائمة `user_uploads`؛ عندها استخدم رابط القناة الظاهر في نافذة المشغّل. قد تظهر إعلانات داخل مشغّل YouTube.
